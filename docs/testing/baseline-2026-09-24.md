## Browser E2E

The repository contains four Playwright spec files. They start `pnpm dev` and
therefore verify browser behavior, not the built Tauri desktop boundary. A
timed browser baseline and flake sample are still required before VFY-04 is
accepted.

## Native E2E and formal verification

No native desktop harness, Lean sources, `lean-toolchain`, or Lake project were
present at baseline. Their first stable runs will establish new comparison
points; they cannot be compared to a previous native/formal runtime.

## Interpretation

These numbers are not deletion targets. A pilot passes only if relevant fault
detection and invariant evidence remain equal or improve while stability,
feedback time, and diagnosis remain within the agreed budgets.
