## Startup timeout

Connector manifest v0 now accepts optional `launch.startup_timeout_s`. Missing values default to 30 seconds (at least the requested 15 seconds); zero is rejected. The value is used for standard stdio-MCP and Crush startup timeouts and Codex's `startup_timeout_sec`. The default is omitted on serialization, preserving legacy manifest/policy output. Focused connector and supervisor-policy tests cover this behavior.
